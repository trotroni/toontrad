02/ Moteurs OCR

Sélection automatique selon le matériel

🏓
PaddleOCR
Très rapide · excellent pour l'asiatique
GPU JA · ZH · EN · FR
👁
EasyOCR
Bon général · multi-langue
GPU Multi
🤖
TrOCR
Microsoft · meilleure qualité texte stylisé
GPU ≥ 6 GB
📖
manga-ocr
Spécialisé manga japonais
GPU JA
📝
Tesseract
Fallback léger · bundlé au build
CPU 7 langues
Logique de sélection
if CUDA disponible:
if VRAM ≥ 6 GB → TrOCR
else          → EasyOCR
else (CPU):
→ Tesseract
📦 Tessdata bundlé
Les modèles Tesseract (eng, jpn, fra, deu, spa, chi_sim, kor) sont téléchargés automatiquement au build via CMake. Zéro intervention manuelle.
🖱 Ajout manuel de bulle
Clic droit sur l'image → "Ajouter une bulle ici". ToonTrad détecte la région (flood fill), crop, OCR, et l'ajoute dans la liste.

→ JSON →
Python
main_ocr.py
Entrée · Tessdata · Args
→
Python
OCRManager.py
Multi-engine · GPU/CPU
C++
ImageCanvas

QGraphicsView custom. Zoom molette, scroll drag, affichage des polygones OCR colorés par confiance. Clic droit contextuel : supprimer une zone ou ajouter une bulle manuellement.

C++
ProjectManager

Singleton. Gère les projets via project.json. Scan automatique des images (PNG, JPG, WebP, TIFF…). Persistance des préférences via QSettings.

C++
BubbleDetector

Flood fill depuis un pixel cliqué. Remonte vers le blanc le plus proche (rayon 80px), détecte la région, filtre par aire et ratio largeur/hauteur.

C++
Exporter

Rendu du texte traduit sur l'image (QPainter). Export .json (avec champs Photoshop), .txt tabulé, .png rendu final.

Python
ocr_engine.py

Détection du matériel via PyTorch. Résout le device (auto → cuda:N ou cpu). Sélection automatique du moteur selon VRAM disponible.

Python
ocr_manager.py

Charge le moteur, limite la VRAM/RAM, lance l'extraction. Retourne une liste de blocs {text, confidence, box} filtrés par seuil de confiance.

Format de données — project.json
{
  "name": "one-piece-ch1100",
  "version": 2,
  "pages": [ // une entrée par image
    {
      "file": "raw/p001.jpg",
      "ocrDone": true,
      "blocks": [
        {
          "id": 1,
          "confidence": 0.94,
          "originalText": "こんにちは！",

04/ Installer

Démarrage rapide

01
Cloner le repo
bash
$ git clone https://github.com/trotroni/toontrad
$ cd toontrad
$ git checkout dev
02
Dépendances Python
bash
$ pip install -r requirements.txt
# GPU CUDA :
$ pip install torch torchvision \
  --index-url https://download.pytorch.org/whl/cu118
03
Build CMake
bash
$ cmake -B build -S .
$ cmake --build build
# → télécharge tessdata auto
# → copie python/ + resources/
