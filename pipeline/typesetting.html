Typesetting

Rendu du texte traduit sur l'image source.

Fonctionnel
Vue d'ensemble

Le typesetting est assuré par Exporter::renderImage() via QPainter. Pour chaque bulle validée, le fond original est effacé (remplissage blanc sur le polygone), puis le texte traduit est centré et rendu dans la zone. Le résultat est une image PNG prête à distribuer.

Processus de rendu
⬜
Effacement

Le polygone de chaque bulle est rempli en blanc (QPainter::drawPolygon) pour supprimer le texte original.

🔤
Rendu texte

Le texte traduit est rendu centré (Qt::AlignCenter + Qt::TextWordWrap) dans le bounding box de la bulle.

🎨
Police

Arial Bold 10px par défaut. La personnalisation de la police par projet est prévue dans une future version.

🖼
Format sortie

QImage ARGB32 → sauvegarde PNG. Même résolution que l'image source, sans perte de qualité.

Implémentation
core/Exporter.cpp — renderImage()
for (const auto& b : blocks) { // Texte à afficher : traduit ou original const QString& text = b.translatedText.isEmpty() ? b.originalText : b.translatedText; // Efface la bulle (fond blanc) p.setBrush(Qt::white); p.setPen(Qt::NoPen); p.drawPolygon(b.polygon); // Rend le texte traduit p.setPen(Qt::black); p.drawText(b.boundingBox, Qt::AlignCenter | Qt::TextWordWrap, text); }
