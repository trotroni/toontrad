OCR

Extraction automatique du texte depuis les images manga.

Fonctionnel
Vue d'ensemble

L'OCR est le cœur de ToonTrad. Le module Python ocr_manager.py sélectionne automatiquement le meilleur moteur selon le matériel disponible (GPU/CPU), lance l'extraction et retourne une liste de blocs {text, confidence, box} au frontend Qt via QProcess.

Les 5 moteurs
PaddleOCR
GPUJA · ZH · EN · FR

Très rapide, excellent pour les langues asiatiques. Utilisé en priorité sur GPU.

EasyOCR
GPUMulti

Sélectionné automatiquement sur GPU avec moins de 6 GB de VRAM.

TrOCR
GPU ≥ 6 GB

Modèle Microsoft. Meilleure qualité pour le texte stylisé. Requiert 6 GB+ de VRAM.

manga-ocr
GPUJA

Spécialisé manga japonais. Utilise EasyOCR pour détecter les zones puis reconnaît texte par texte.

Tesseract
CPU7 langues

Fallback CPU léger. Modèles bundlés automatiquement au build CMake (resources/tessdata/).

Sélection automatique
if CUDA disponible:
if VRAM ≥ 6 GB → TrOCR
else          → EasyOCR
else (CPU):
→ Tesseract
Format de sortie
stdout → JSON
[ { "text": "こんにちは！", "confidence": 0.94, "box": [[12,8],[180,8],[180,42],[12,42]] }, // ... autres blocs ]
Ajout manuel de bulle

Clic droit sur l'image → Ajouter une bulle ici. ToonTrad lance un flood fill depuis le pixel cliqué pour détecter la région blanche (rayon de recherche : 80px), crop l'image, lance l'OCR sur ce crop, puis réintègre les coordonnées dans l'espace image complet.
