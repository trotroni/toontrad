Téléchargement automatique des planches brutes.

Planifié
Vue d'ensemble

Cette étape a pour objectif d'automatiser la récupération des pages RAW (non éditées) depuis les sources de manga/webtoon. Elle est actuellement planifiée et sera intégrée dans une future version de ToonTrad.

L'idée est de permettre à une équipe de scantrad de simplement renseigner un identifiant de chapitre et de laisser ToonTrad récupérer et organiser toutes les planches dans la structure de projet attendue.

Fonctionnement prévu
🔗
Sources configurables

URL ou plugin par source. La configuration sera stockée dans le projet.

📁
Organisation auto

Les fichiers téléchargés sont rangés dans raw/ et indexés dans project.json.

🔄
Reprise sur erreur

Les fichiers déjà présents sont détectés et ignorés. Seules les planches manquantes sont téléchargées.

📷
Formats supportés

PNG, JPG, WebP, AVIF. Conversion automatique vers PNG si nécessaire pour la compatibilité OCR.
