3 formats de sortie + CI/CD GitHub Actions.

Fonctionnel
Formats d'export
🖼
PNG rendu

Image finale avec le texte traduit inséré dans les bulles. Même résolution que l'original. Prête à distribuer.

📄
JSON

Tous les blocs avec coordonnées, textes, statuts, confiance + champs Photoshop (cx, cy, x, y, w, h) pour intégration externe.

📝
TXT tabulé

Format plat : ID | IMG | RAW | TL FR | STATUT | CONF | X | Y | W | H | POLYGONE | TL | NOTE. Compatible tableurs.

Structure JSON exporté
export.json — format v2
{ "image": "p001.jpg", "version": 2, "blocks": [ { "id": 1, "originalText": "こんにちは！", "translatedText": "Bonjour !", "confidence": 0.94, "boundingBox": {"x":120,"y":45,"w":180,"h":40}, "photoshop": {"x":120,"y":45,"cx":210,"cy":65} } ] }
CI/CD GitHub Actions

Un workflow GitHub Actions est configuré pour builder, tester et packager ToonTrad automatiquement. Il se déclenche lors de la publication d'un tag versionné (v*.*.*) et crée une GitHub Release avec les binaires en pièce jointe.

.github/workflows/release.yml
on: push: tags: ['v*.*.*'] jobs: build: # cmake --build → tests → package # → GitHub Release + assets
