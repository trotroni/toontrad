Traduction

Traduction assistée par IA, édition manuelle inline.

En cours
Vue d'ensemble

La traduction dans ToonTrad est hybride : une API (DeepL) fournit une première traduction automatique, et le traducteur humain la valide ou la corrige directement dans l'interface Qt, bulle par bulle. La traduction manuelle reste toujours possible sans clé API.

Fonctionnement
🔑
DeepL API

La clé API est configurée dans les paramètres. Sans clé, le texte original est conservé pour traduction manuelle.

✏️
Édition inline

Chaque bulle a un champ originalText et un champ translatedText éditable directement dans le panneau OCR.

🔁
Sync temps réel

Les modifications sont enregistrées en mémoire à chaque frappe et persistées dans project.json à la sauvegarde.

🌐
Paires de langues

Toute paire supportée par DeepL est disponible. Configurable depuis la fenêtre des paramètres.

État actuel

La structure Translator.cpp est en place. L'édition manuelle inline est fonctionnelle. L'intégration de l'appel DeepL API est en cours de développement — la méthode translateViaDeepL() retourne actuellement le texte brut en attendant l'implémentation HTTP.
